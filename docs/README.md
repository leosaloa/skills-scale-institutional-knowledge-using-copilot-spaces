# OctoAcme Project Management Docs

This folder contains OctoAcme's project management processes and guidance. Use these documents as a shared reference for planning and delivering cross-functional projects.

## Project management process overview

OctoAcme follows a customer-first, iterative approach with clear ownership, data-informed decisions, and continuous learning. Projects move through initiation (validate the need and align stakeholders), planning (prioritize and estimate work, milestones, risks, and dependencies), execution and tracking (deliver and test increments, communicate progress, and escalate blockers), release and deployment (verify and communicate releases), and retrospective (capture lessons and track improvements). Project Managers coordinate delivery, Product Managers own outcomes and priorities, and the delivery team builds and validates increments. Regular team and stakeholder communication keeps progress, decisions, and risks visible.
